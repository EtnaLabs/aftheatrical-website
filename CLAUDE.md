# AF Theatricals Website

Static marketing site for AF Theatricals (aftheatricals.com) — a New York City
experiential production company. No framework, no build step: `index.html` is the
entire site (inline CSS + JS).

## Architecture

| Piece | What / where |
|---|---|
| Site | `index.html` (single page, ~3,000 lines, inline styles/scripts) |
| 404 page | `404.html` (GitHub Pages serves it automatically) |
| Hosting | **GitHub Pages**, repo `EtnaLabs/aftheatrical-website`, `main` branch, custom domain via `CNAME` |
| Large media | Cloudflare R2 bucket `af-theatricals-assets`, public URL `https://pub-43545990593741a6b5e64edec34eabee.r2.dev/...` |
| Optimized images | `assets/optimized/` (WebP/AVIF/JPEG variants, served by Pages, generated by `scripts/optimize-images.js`) |
| Analytics | GA4 property "AF Theatricals Website" (account "AF Theatricals"), measurement ID `G-CK9F98M5DE`, gtag snippet in `<head>` of `index.html` and `404.html` |
| SEO metrics history | `seo-metrics.json` — dated Lighthouse/audit snapshots; append a new entry when re-auditing |

`saisei-index.html`, `other-websites/`, `.assets/` are local-only (gitignored)
design references / source material — not part of the deployed site.

## Deploy

Push to `main` — that's it. GitHub Pages rebuilds in ~1–5 minutes.

```sh
git push origin main
# verify what's live:
curl -sI https://aftheatricals.com | grep last-modified
```

The repo is **public** (required for the Pages setup): everything committed is
world-readable AND directly downloadable at `https://aftheatricals.com/<path>`.
Never commit guest lists, CSVs with personal data, tokens, or `.env` —
`.gitignore` blocks the known offenders; keep it that way. Private data lives
outside the repo in `~/aftheatrical-private-data/`.

## Images

Heavy originals are uploaded to R2 and referenced by full `pub-….r2.dev` URLs.
Hero images + Peppino poster use optimized local variants instead:

```sh
npm install sharp          # one-off, anywhere
node scripts/optimize-images.js   # reads .assets/, writes assets/optimized/
```

Hero `<picture>` elements in `index.html` use
`/assets/optimized/hero/<name>-{640,1280,1920}w.{avif,webp,jpg}`.
When adding a new hero image, generate all nine variants and keep the
`width`/`height` attributes on the `<img>` to avoid layout shift.

To upload anything new to R2:
```sh
npx wrangler r2 object put af-theatricals-assets/assets/<path> --file=<local-file>
```

## SEO upkeep

- `sitemap.xml`: bump `<lastmod>` on meaningful content changes.
- `robots.txt` allows everything and points at the sitemap.
- Structured data (JSON-LD `Organization` + `TheaterEvent`) is inline in
  `index.html` — update the event schema when shows change.
- GA4: https://analytics.google.com → account "AF Theatricals". Google Search
  Console is verified for the domain; submit `sitemap.xml` there after big changes.
- Re-audit: run Lighthouse (`npx lighthouse https://aftheatricals.com --output=json`)
  and append a dated entry to `seo-metrics.json` to compare against the baseline.
